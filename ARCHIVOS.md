# Archivos del usuario (Archivos de Apple → iCloud Drive → MaurInventario)

Cada vez que entregues un archivo al usuario, di en qué carpeta guardarlo (ruta exacta) y si hace falta crear una carpeta nueva. Si una versión sustituye a otra, indica que la antigua va a `09 Archivo`.

| Carpeta | Qué va |
|---|---|
| `01 Marca` | Logo, iconos, colores, tipografías |
| `02 App` | Enlaces · `Guías de uso` · `Documentación técnica` |
| `03 Capturas/Ordenador` · `Móvil` · `SaaS (versión de pago)` | Pantallas de la app (datos de ejemplo) |
| `04 Vídeos/Promo 75 s` · `04 Vídeos/Serie TikTok` | Vídeos terminados (nueva serie → nueva subcarpeta) |
| `05 Portadas/<serie>` | Portadas y miniaturas |
| `06 Guiones` | Guiones, storyboards, conceptos, investigación |
| `07 Redes sociales` | Calendarios, copys, hashtags |
| `08 Audio` | Música, voces |
| `09 Archivo` | Versiones antiguas (no se borran) |
| `10 Código` | Copias de seguridad del código por versión (zip de main, SaaS, SaaS con permisos) |
| `11 Base de datos` | Instaladores SQL, plantilla de variables (sin claves) · `Copias de datos/AAAA-MM-DD` |

Nombres: número de orden + descripción corta en español («01 Ventas por correo.mp4»). Archivos de más de 30 MB no se pueden enviar por el chat: entrega una versión más ligera o en partes y dilo.

Nunca entregues claves, contraseñas ni archivos `.env` reales.
